# V2 Batch 6A-6D + UX-1

Date: 2026-06-09

## Scope

Batch 6 reduces high-impact misses after the Batch 5 local allowance pass. The goal is not only more records, but a safer user path when records are incomplete:

- show official or cross-checked local allowance cards where the county matrix was still thin;
- add central cards for common searches that users phrase informally;
- mark source completeness directly on result cards;
- give a useful next step when search returns no exact match.

## 6B Source Quality Guardrail

Result cards now display a source-confidence row:

- Stronger source: dated source, checked source, or official updated source.
- Cross-check needed: official entry exists, but yearly amount/details depend on a cross-check.
- Local confirmation needed: official signal exists but local application detail is incomplete or unstable.
- Recheck needed: mostly for private or volatile program pages.

This prevents weak coverage from looking as complete as direct official application pages.

## 6C Missing-Data Safety Net

The site now handles likely missing-data cases in the UI:

- no-result state suggests broader search terms;
- no-result buttons can clear narrow filters;
- central fallbacks such as `1957 welfare hotline`, `social affairs bureau / township office`, and `social welfare center` are suggested;
- cards show match-reason chips so users can see why a result appeared.

This is the current static-site mechanism for reducing missed help: make uncertainty visible, offer a route to a human or official office, and avoid dead-end searches.
